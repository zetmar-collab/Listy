# Listy 1.0.2 — studio playlist

Pierwsze publiczne wydanie aplikacji Windows do tworzenia playlist, z polskim interfejsem.

## Pobieranie

Pobierz plik **Listy.exe** z załączników tego wydania i uruchom. To wersja przenośna dla Windows x64 z dołączonym środowiskiem .NET — bez instalatora, konta i serwera.

Plik **SHA256SUMS.txt** zawiera sumę kontrolną EXE. Polecenie sprawdzające: `Get-FileHash .\Listy.exe -Algorithm SHA256`.

## Funkcje

- Skanowanie katalogu i podkatalogów z filtrem formatów muzyki.
- Tworzenie list osobno w folderach albumów lub zbiorczo w katalogu głównym albo podkatalogu.
- Nazwa playlisty pobierana z nazwy folderu albumu.
- Odczyt i zapis M3U8, M3U, PLS, XSPF i WPL.
- Ręczne dodawanie utworów, przeciąganie plików i zmiana kolejności.
- Podgląd listy utworów i treści pliku playlisty.
- Zmiana nazwy oraz przenoszenie zaznaczonych starych playlist do Kosza z potwierdzeniem.
- Własna ikona aplikacji i przykładowa biblioteka w repozytorium.

Automatyczne tworzenie pomija istniejące playlisty. Program nie odtwarza muzyki i rozpoznaje albumy po folderach, bez analizy tagów.

Weryfikacja wydania: 45 testów automatycznych zakończonych poprawnie oraz kompilacja wersji przenośnej.
