# Listy 1.2.0 — biblioteka, edytor i bezpieczne aktualizacje

## Polski

- Wybór albumów checkboxami oraz wyszukiwanie albumów, wykonawców, utworów i playlist.
- Zapamiętywanie katalogu, filtrów, formatu, trybu zapisu, zaznaczeń i rozmiaru okna.
- Istniejące playlisty: pomijanie, aktualizacja z kopią zapasową albo kolejna wersja pliku.
- Naprawiony podgląd polskich znaków i niezależne raportowanie błędnych albumów.
- Operacje w tle, postęp i anulowanie między przetwarzanymi plikami.
- Zachowanie metadanych przy edycji w tym samym formacie, ostrzeżenie przy konwersji.
- Zapisz / Odrzuć / Anuluj, cofanie/ponawianie, przeciąganie kolejności i skróty klawiaturowe.
- Kontrola brakujących plików, duplikatów i pustych list; naprawa ścieżek po przeniesieniu muzyki.
- Odczyt tagów, czasu utworów i łącznego czasu playlisty; sortowanie według nazw lub tagów.
- Polski i angielski interfejs.

## English

- Album selection, search, persistent settings and window size.
- Existing-playlist policies: skip, update with an atomic backup, or save a new version.
- Correct legacy-encoding preview and per-album error isolation.
- Background operations, progress and cancellation between files.
- Same-format metadata preservation, conversion warnings, Save / Discard / Cancel.
- Undo/redo, drag reordering and keyboard shortcuts.
- Missing-file, duplicate and empty-playlist checks; path-prefix repair.
- Audio tags, durations, playlist totals and sorting by tags or names.

Download **Listy.exe** (portable Windows x64, includes .NET).
**SHA256SUMS.txt** contains the executable checksum.
ATL.NET license notices are embedded in the About / licenses window and included as a release attachment.

Validation: 72 core/integration tests and 6 WPF window tests.
Audio files are never modified by tag reading. Undo affects playlist entries in memory; disk updates are protected by backups.
